Gerador de nome padrão de oferta (HTML + CSS + JS, sem dependências).

Fórmula: [Ação]-[Origem].[Segmento].[Vigência].[Detalhe].[Abrangência]-[Id]-[Observação]

Id (4 caracteres): dia do mês (1) + inicial do nome de quem gerou (1) + 2 aleatórios. Dia: 1-9 = dias 1 a 9; A=10, B=11, ... V=31. Exemplo: Oferta-IC.1.FD.RE.L01-QTK7-COCACOLA (dia 26, Tatiana, sorteio K7)

Arquivos: index.html, style.css, app.js, dados.js (códigos), config.js (URL do Apps Script), Code.gs (script da planilha). Sem URL no config.js o site funciona em modo local (nomes só no navegador).
